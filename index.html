myDATA API · Έσοδα και έξοδα

Ανάγνωση συγκεντρωτικών εσόδων και εξόδων · Καμία αποστολή ή έκδοση παραστατικών.

Μη συνδεδεμένο

Συνδέσου στον προσωπικό σου λογαριασμό για να καταχωρήσεις τα στοιχεία myDATA.

Το API key αποθηκεύεται κρυπτογραφημένο στον server. Δεν είναι ο κωδικός Taxisnet. Το υπάρχον κλειδί δεν εμφανίζεται ξανά.

Άντληση εσόδων και εξόδων

Κάθε επιτυχής άντληση αντικαθιστά το προηγούμενο στιγμιότυπο. Επίλεξε ολόκληρη την περίοδο που χρειάζεσαι (έως 366 ημέρες). Οι γραμμές είναι συγκεντρωτικές ανά ημέρα, αντισυμβαλλόμενο και τύπο παραστατικού.
