# Dashboard design references

Reviewed 17 November 2026 via GitHub search and repository source:

- https://github.com/tabler/tabler (about 42k stars at review): README and `core/scss/_variables.scss`; compact admin layouts, 6px base radius, system typography, blue actions, clear tables and light/dark tokens.
- https://github.com/ant-design/ant-design-pro (about 39k stars at review): README and dashboard directory; analysis/workplace hierarchy, consistent navigation and compact data presentation.

These projects informed the layout and hierarchy. No framework source, proprietary theme, bundled charts or template assets were copied; this app remains dependency-free. SVG icons use simple local geometric paths and no remote font/icon service. The palette, spacing, sidebar, responsive layout, copy and icon treatment were reworked for an accounting workflow.
